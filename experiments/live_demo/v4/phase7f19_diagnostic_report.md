## 2. Preprocessing Parity Audit
A rigorous code-level audit revealed a critical discrepancy between the V2 offline dataset generation and the V4 Live Pipeline:

- **Offline Training/Test Path (`AntiImpersonationV4Dataset`):**
  Images are loaded from disk (`data/aligned_112/train/...`). These files were previously generated by passing unaligned faces to `align_face`, converting to BGR, and explicitly saving them to disk using `cv2.imwrite("...jpg")`. During training/testing, they are read via `Image.open(img_path).convert('RGB')`, preserving standard JPEG compression artifacts before tensor normalization.
- **Live Inference Path (`LiveInferencePipelineV4`):**
  The unaligned frame is passed to `align_face`, producing an in-memory 112x112 RGB NumPy array. This raw array is passed directly to `transforms.ToPILImage()` and then normalized. **No JPEG compression is applied.**

## 3. Controlled Input Comparison (Genuine Frame `05.jpg`)
To isolate the cause, the exact aligned 112x112 array from `05.jpg` was routed through two separate paths into the frozen V4 Visual Branch:

**Path A (Live Emulator):** In-memory NumPy array → `ToPILImage()` → `ToTensor()`
- Tensor Hash: `4a7e1b53`
- V4 Visual Branch Logit: `1.0507` 
- **P(Synthetic) Result**: **74.09%** (False Positive)

**Path B (Dataset Emulator):** In-memory NumPy array → `cv2.imwrite(.jpg)` → `Image.open()` → `ToTensor()`
- Tensor Hash: `3aa5a3e9`
- V4 Visual Branch Logit: `-1.6555`
- **P(Synthetic) Result**: **16.03%** (Correct Genuine Negative)

### Diagnostic Verdict
**Observed Evidence**: Saving the exact same aligned image to a JPEG before inference correctly drops the `P(Synthetic)` score by 58 absolute percentage points, converting the network's prediction from a False Positive to a True Negative.
**Supported Interpretation**: The V4 EfficientNet visual branch mathematically learned to associate `cv2.imwrite` JPEG compression blocking artifacts with the "Genuine" class, and their absence with the "Synthetic" class. 
**Conclusion**: The cause is **fully identified**. The discrepancy is a preprocessing shortcut artifact. The offline V4 experiment is quantitatively sound relative to its dataset, but the live pipeline suffers a False Positive because it bypasses the dataset's artifact distribution by remaining in-memory.
